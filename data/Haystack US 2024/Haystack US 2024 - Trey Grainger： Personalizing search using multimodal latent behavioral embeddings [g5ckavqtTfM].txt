Personalization spans the differences between these contexts. In traditional keyword search, we have the user input, while in recommendations, we consider user profiles. However, there's a huge area between personalized queries and user-guided recommendations. 

If we delve into collaborative filtering, we have no knowledge of content and purely focus on user interactions. Examples include using alternating least squares (ALS) to convert user-item interaction matrices into latent features for understanding user and item preferences. 

For personalized search, we create embeddings for user interactions, leading to boosted search results and contextual personalization. Dynamic clustering and weighted averages between query vectors allow flexibility in applying personalization.
