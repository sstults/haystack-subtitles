**Evgeniya Sukhodolskaya**: Hello. While my colleague is the real author of this idea, I'm here to present it. The focus is on turning any embedding model into a late interaction model. We've talked about rankers like ColBERT which can be quite heavy, integrating both a query and document into a single embedding model evaluation, resulting in precise but slow performance.

Late interaction models provide more precise ranking by representing queries and documents in a manner allowing for term interactions at inference time. The idea is simple: instead of creating a complex infrastructure, what if we take existing dense models and apply late interaction logic? Surprisingly, this method has shown success through experimentation on BEIR datasets, indicating sharper performance without a heavy infrastructure.

This holds cost-effectiveness benefits with smaller models like MiniLM and BGE while not requiring storage-heavy resources, as quantization can alleviate storage concerns. Overall, using these simpler models for dynamic ranking seems not only feasible but advisable.

The article "Late Interaction Models" by my colleague provides more details, and you can repeat experiments from the GitHub repository. Thank you.
